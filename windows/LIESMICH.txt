SPLITT-TOOL FÜR WINDOWS
=======================

Teilt große PDFs (bis 1000 MB) kapitelweise in Teile, die Claude annimmt.
Inhalte werden nie verändert: Seiten werden 1:1 kopiert und bitgenau geprüft.

Keine Adminrechte nötig. Java ist bereits enthalten.

INSTALLIEREN (empfohlen)
  1. Splitt-Tool-Setup.exe doppelklicken.
  2. Falls „Der Computer wurde durch Windows geschützt“ erscheint:
     auf „Weitere Informationen“ klicken, dann auf „Trotzdem ausführen“.
     (Das kommt, weil das Programm nicht bei Microsoft gekauft-signiert ist. Es ist kein Virus.)
  3. „Weiter“ → „Installieren“ → „Fertig stellen“.
  Danach findest du das Splitt-Tool im Startmenü und auf dem Desktop.
  Rechtsklick auf eine PDF → „Mit Splitt-Tool aufteilen“ geht auch
  (Windows 11: erst „Weitere Optionen anzeigen“).

OHNE INSTALLATION (Zip-Paket)
  Ordner entpacken und Splitt-Tool.exe doppelklicken.

UPDATES
  Der Knopf „Update“ oben rechts leuchtet rot, wenn es eine neue Version gibt.
  Ein Klick öffnet den Download der neuen Splitt-Tool-Setup.exe im Browser.
  Das Programm verändert sich nie selbst. Zum Aktualisieren das Splitt-Tool schließen
  und die heruntergeladene Setup.exe starten. Einstellungen bleiben erhalten.

DEINSTALLIEREN
  Einstellungen → Apps → Installierte Apps → Splitt-Tool → Deinstallieren.

Auf Firmenrechnern kann die IT unbekannte Programme sperren – dann bitte die IT fragen.
